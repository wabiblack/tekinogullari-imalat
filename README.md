# TEKİNOĞULLARI İMALAT

Demir doğrama, ferforje kapı, damperli / dampersiz römork imalatı, patpat römorku damper dönüşümü ve kaynak işleri için kurumsal web sitesi.

## Başlangıç
Bu ilk sürüm **statik HTML, CSS ve JavaScript** ile hazırlanmıştır; derleme veya paket kurulumu gerektirmez. `index.html` dosyasını tarayıcıda açarak çalıştırabilirsiniz.

## Yayınlama (GitHub Pages)
GitHub deposunda **Settings → Pages → Build and deployment → Deploy from a branch** seçin. Branch **main**, klasör **/(root)** olsun ve **Save** ile kaydedin.

Yayınlandıktan sonra varsayılan adres: https://wabiblack.github.io/tekinogullari-imalat/

## Güncellenmesi gerekenler
- Gerçek atölye ve tamamlanan proje fotoğrafları
- İşletme telefonu, WhatsApp numarası ve adresi
- Doğrulanmış işletme bilgileri
- Logo ve marka görselleri

**Not:** Teklif formu henüz veri göndermez. Kullanıcının doldurduğu içeriği kopyalamasına yarar. WhatsApp numarası eklendiğinde gerçek iletişim akışına bağlanabilir.
